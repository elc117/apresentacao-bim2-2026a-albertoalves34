# Projeto Java - Turma

Projeto simples com 3 classes principais:

- `Aluno.java`: representa um aluno (nome e nota).
- `Turma.java`: guarda lista de alunos e calcula media/taxa de aprovacao.
- `Teste.java`: classe com `main` para testar o funcionamento.

## Como executar

No terminal, dentro da pasta do projeto:

```bash
javac Aluno.java Turma.java Teste.java
java Teste
```

## Saida esperada

O programa imprime:

- lista dos alunos
- media da turma
- taxa de aprovacao em porcentagem
